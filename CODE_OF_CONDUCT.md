# Código de Conduta

## Compromisso

Este projeto busca um ambiente respeitoso, técnico e acolhedor para todas as
pessoas, independentemente de experiência, identidade, origem ou afiliação.

## Comportamento esperado

- Seja respeitoso e objetivo em issues, PRs, discussões e revisões.
- Critique ideias e código, não pessoas.
- Presuma boa-fé; peça contexto antes de acusar.
- Respeite escopo, licença e decisões registradas em ADR.
- Não publique dados privados, segredos ou conteúdo de arquivos de terceiros.

## Comportamento inaceitável

- Assédio, discriminação, ameaça, intimidação ou ataques pessoais.
- Divulgação de informação privada sem consentimento.
- Spam, trolling ou interrupção deliberada de discussões.
- Uso do projeto para acesso não autorizado a sistemas ou dados.

## Escopo

Aplica-se a issues, PRs, discussões, revisões e eventos do projeto.

## Aplicação

O mantenedor pode advertir, remover conteúdo ou bloquear participantes em caso
de violação. Relatos devem ser feitos em privado ao mantenedor pelo perfil do
GitHub (<https://github.com/maquineh>). Para vulnerabilidades, use
`SECURITY.md`, não uma issue pública.

Este texto é uma adaptação do
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
